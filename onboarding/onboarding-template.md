## FAQs

**What if I can't complete my deliverable on time?**
Let [PM Name] know as early as possible so we can adjust. Do not wait until the deadline.

**What if I have a question and can't reach anyone?**
Post in [#general] and tag [PM Name]. We monitor this channel throughout the project.

**What if the scope changes?**
All scope changes go through the PM. Do not accept new requests directly from the client or stakeholders.

**What if I run into a blocker?**
Post in [#blockers] immediately with a description of the issue. The team will help.
