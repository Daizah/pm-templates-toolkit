# PM Templates Toolkit

**Free, production-ready project management templates for PMs, team leads, and nonprofit coordinators.**

Built by [Daizah Patterson](https://pattersonstrategicsolutions.com) — PMP · PSM · MBA · Dallas, TX

---

## Why This Exists

Most teams waste hours building project documents from scratch on every new engagement. These templates are designed to be downloaded, customized, and deployed in minutes so you can focus on delivering results instead of formatting documents.

Every template here has been used in real projects across enterprise B2B telecom, 48-hour nonprofit website sprints, and volunteer program coordination.

## How to Use

1. Click any template file above
2. Click **Raw** to view the plain text version
3. Copy and paste into your preferred tool — Notion, Google Docs, Word, Confluence, or any markdown editor
4. Customize all fields marked with `[brackets]` for your specific project
